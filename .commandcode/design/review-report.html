Computed style on the focused control inside the open popover: outline auto 1px, box-shadow none. Marginal against the 2–3px, offset, 3:1-contrast bar on a near-black surface.

FIX: /design interaction — focus-visible rings (2px, offset, role-consistent color) on tabs, rail buttons, and model rows.
P3

Rail shows the shown provider, never the selected one

The accent highlight tracks whichever provider you clicked; nothing marks the provider owning the current selection. Drill away and the check's location is lost from view.

FIX: /design interaction — selected-dot on the rail icon whose provider owns the role's selection (moot if P1 lands).
P3

Arrow-key navigation is not wired

Rows are plain buttons in a Popover with role="radiogroup" — semantics that imply arrow-key movement the implementation doesn't provide. Tab reaches items; arrows were not verified to move between them, and there is no roving tabindex in code.

FIX: /design interaction — add roving tabindex/arrow handling, or drop radiogroup semantics so the a11y tree doesn't over-promise.
