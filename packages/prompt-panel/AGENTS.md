# Prompt Panel Package DOX

## Purpose

- Owns landing-page prompt panel UI + landing conversation domain model it renders. Source-consumed by `@workspace/client` (and future consumers) via `@workspace/prompt-panel`.

## Ownership

- `src/prompt-panel.tsx`: root `PromptPanel` component, its `PromptPanelProps`, horizontal-resize `ResizeState`/handlers, vertical floating resize handlers, and accessible edge handles. `src/panel-height.ts` owns bounded top/bottom resize geometry; its tests cover pinned edges, minimum size, viewport bounds, and avoiding accidental docking.
- `src/`: panel UI components (`panel-header`, `panel-body`, `panel-command-menu`, `composer`, `turn-message`, `spend-popover`, `turn-steps`, `streamdown-content`, `model-dropdown`, `status-pill`, `chat-empty-state`, icons) + helpers (`panel-constants`, `panel-status`, `panel-storage`, `model-role-meta`, `spend-summary`, `format`, `keyboard-shortcut`). Every step row (tool blocks in `turn-steps`, thinking + memory markers + text bubbles in `turn-message`) renders the shared `StepElapsed` timer (`step-elapsed.tsx`, 1s tick) while active and the frozen `durationMs` once finished; the composer toolbar shows the whole-turn `StepElapsed` (ticks while streaming, freezes at turn `durationMs`).
- `src/panel-storage.ts`: read-only panel position/layout persistence — owns `landing.promptPanel.position.v2` localStorage key, `StoredPanelState` (`x`/`y`, `collapsed`, `layout`, `width`/`height`), `readStoredPanelState`, public `readStoredPanelLayout` (effective layout; treats collapsed panel as `floating` so minimized panel reserves no docked column) + `readStoredPanelWidth`. Component keeps write logic (`writeStoredPanelState`) — intertwined w/ docked-side derivation.
- `src/domain.ts`: landing conversation domain model — model options (text `LANDING_MODEL_OPTIONS`, + `LANDING_VISION_MODEL_OPTIONS` + `LANDING_IMAGE_MODEL_OPTIONS`), `MODEL_PRICING` per-1M-token USD snapshot keyed by base model id (bundled offline fallback; live prices arrive via the `modelPricing` prop — client `useModelPricing` hook fetches server's `GET /api/models` OpenRouter proxy; `modelPricingFor(id, map?)` strips `:nitro` etc.) + `formatTokenPrice` helpers, per-category `LandingModels` selection + `DEFAULT_LANDING_MODELS` + `resolveLandingModels`, attachment types, conversation model (`LandingTurn`, incl durable `stopped` terminal state, `TurnPart` variants — incl `MemoryPart` OM compaction markers rendered by `turn-message.tsx` as a separator `Marker` row — optional tool-call arg images, `RetryPart` inlined), cost/usage types, `LandingAgentSendInput`, formatting helpers.
- `src/keyboard-shortcuts.ts`: `KEYBOARD_SHORTCUTS` metadata + types.
- `src/index.ts`: public barrel (`PromptPanel`, `PromptPanelProps`, `readStoredPanelLayout`, `readStoredPanelWidth`, `PANEL_WIDTH`, `MIN_PANEL_WIDTH`, `maxPanelWidth`, `clampPanelWidth`, `DEFAULT_PREVIEW_VIEWPORT`, `PREVIEW_VIEWPORTS`, domain model, keyboard-shortcuts, panel-constants types incl `PreviewViewport`).

## Local Contracts

- Source-consumed like `@workspace/ui`: `exports` point at `./src/*`, no build step, consumers import through package exports (`@workspace/prompt-panel`, `@workspace/prompt-panel/domain`, `@workspace/prompt-panel/keyboard-shortcuts`).
- Depends on `@workspace/ui` + catalog deps (`lucide-react`, `react-hotkeys-hook`, `streamdown`, `@streamdown/code`); `react`/`react-dom` are peer deps. Tailwind design tokens from `packages/ui/src/styles/globals.css` (referenced by this pkg's oxlint/oxfmt configs).
- Package owns **domain model only**. Must not import app code, reference `import.meta.env`, or contain SSE/transport logic. `RetryPart` defined inline (not extending app's wire `RetryEvent`) to avoid package→app dependency.
- Model inventory includes GLM 5.3 Flash, Qwen 3.8 Flash, GPT-6 Astra + Astra Pro, and Claude Fable 5.1 in Text + Vision. GPT-5.6 variants, Claude Fable 5, and Ox Alpha are excluded from picker options, pricing snapshots, and icon mappings. Verify additions against OpenRouter's live catalog; keep Text `:nitro` variants, Vision capability membership, prices, and icons aligned.
- App behavior is injected via props: controlled `draft`/`onDraftChange`, hydration/storage feedback, connection state/retry, `onRetryTurn`, `onLocateElement`, current project name, and stopping state; `onSend(input)` resolves `{ turnId, outcome: 'accepted'|'rejected'|'unknown', reason? }`; the panel snapshots its draft revision and clears only a matching unchanged revision after confirmed acceptance. Rejected/unknown sends keep prompt and attachment input, including edits made while acknowledgment is pending. Enter ignores IME composition. Image references show thumbnails and a titled enlarge dialog; element references show text excerpts and Locate. Additional app behavior: navigation through `onAllProjects` (keyboard shortcut) and injected `projectSwitcher` (header view), rename and other page menu actions through `pageActions`, theme through `theme`/`onToggleTheme`, autocompaction through `compactionPercent`/`onCompactionPercentChange`, and effective layout through optional `onLayoutChange` (collapsed reports floating). The client owns preview viewport, reload, and export behavior and injects their menu items into `PanelSettingsMenu`; all editor controls stay in one unified panel. `PreviewViewportMenu` remains reusable via the public components export. The package imports no router or app theme context.
- Dropdown-menu triggers in `src/panel-command-menu.tsx` (`PanelLayoutMenu`, `PreviewViewportMenu`, `PanelSettingsMenu`) wrap `DropdownMenuTrigger` in Radix `Tooltip`. Each menu controls own `open` state (`PanelLayoutMenu` via parent-controlled `open` prop; others via local `useState`) and binds `Tooltip open={open ? false : undefined}` so tooltip forced closed while menu open — w/o this tooltip lingers/overlaps menu content, since pointer stays hovered on stationary trigger and `TooltipProvider` uses `delayDuration={0}`. `PreviewViewportMenu`'s trigger icon reflects current selection (`Monitor`/`Tablet`/`Smartphone`); choices render as radio items with a selected indicator and 390px/768px/full-width labels. Reuse this pattern for any new header dropdown w/ tooltip on trigger.
- `PanelTheme = 'dark' | 'light' | 'system'` lives in `src/panel-constants.ts`, alongside `PreviewViewport` (`'desktop' | 'mobile' | 'tablet'`), ordered `PREVIEW_VIEWPORTS` list, `DEFAULT_PREVIEW_VIEWPORT` (`'desktop'`), `MIN_PANEL_WIDTH` (default `PANEL_WIDTH` equals min), `maxPanelWidth()` (at least the minimum usable width, half viewport on wider screens), `clampPanelWidth(width, max?)`, `PANEL_WIDTH_CSS_VAR` (`--landing-panel-width` custom-property name).
- Panel horizontally resizable from both edges. Handles are focusable separators with ARIA values; Left/Right change width by 16px (Shift: 48px), Home selects minimum, End maximum. Left/right docking fills the entire viewport height, without top or bottom gaps. Rendered width **is** `--landing-panel-width` CSS custom property, registered as typed `@property` in `packages/ui` globals (CSS `initial-value` default, so no JS needed for first paint; can be `transition`ed later) — panel never sets width from React inline value. Numeric width in ref (no React width state, no re-render during gesture); `setPanelWidthVar` writes var on `:root` on mount + while resizing; width persists via `writeStoredPanelState`. Resize mirrors position drag: pointer-captured on a stable gesture element (the title element for title drags, the header for bare header drags, and the separator for resize; never a volatile text/icon child), rAF-throttled, direct-DOM writes during gesture, finalized on `pointerup` + `onLostPointerCapture`/`onPointerCancel` so lost capture (mid-gesture re-render, OS interruption, or cursor leaving window) never strands gesture; both finalizers idempotent (drag tolerates second call; resize returns early once `ResizeState` cleared). Right-edge handle pins panel left; left-edge handle pins panel right (and repositions `left`); each clamped to `[MIN_PANEL_WIDTH, maxPanelWidth()]` + available viewport so panel cannot overflow. Section carries `data-landing-prompt-panel`, `data-layout`, `data-collapsed`, and, while an edge resize is active, `data-resizing`. Minimize hides the mounted header, composer, and conversation and exposes only the 56px transparent draggable launcher, preserving draft text, attachments, and scroll position. Restoring returns focus to the composer; collapsing does not focus the input or summon the software keyboard. Editor disables preview-offset transitions while resizing.
- Cost formatting inside popover renders USD w/ exactly 4 digits after decimal point for zero, tiny, larger costs; do not use less-than-cent shorthand there. Icon-free spend trigger displays only dollar amount rounded to 2 decimals. Conversation no longer renders per-turn Spend / tokens blocks. `SpendPopover` sits immediately after model selector in composer, aggregates latest `stats` snapshot from every turn (incl active turn), while the completed-turn count excludes streaming turns, updates cumulative project cost, cost categories, token counts whenever rolling stats arrive; token breakdown shows Input, Output, Cached (zero when unavailable) w/o Reasoning row; legacy stats w/o breakdown count full cost as LLM spend. Cost-category rows reuse `MODEL_ROLE_META` so Text/LLM, Image, Vision icons + colors match model dropdown; Scrape uses local Firecrawl brand mark in specified OKLCH orange. LLM, image gen, vision OCR, scrape, Input, Output, Cached rows stay visible w/ zero values when project has no matching usage.
- `TurnToolBlock` renders validated `http(s)`, root-relative, or supported raster data-URL images inside expanded Args section. Analyze-image previews from client-only attachment payload; screenshot previews from server's persisted screenshot URL. Keep image bytes out of durable JSON logs.

## Work Guidance

- Compactness is a product constraint: header uses equal 3px padding on every side (35px total, 51px for touch), compact 28px controls with larger touch targets, 12px message padding, and a small editable starter section. The composer has a small visible functional label and a compact resting text field. Validate in the actual 352px panel and 320px phone viewport.
- Visual language: compact glass assistant with a single Projects/title/status/control header, square diagnostic blocks, and an unboxed composer. Requests use a compact monospace prompt marker; real activity appears before the plain-text result, with tool diagnostics behind a disclosure. All rectangular surfaces and controls use square (0px) corners. Empty chat offers three editable starter prompts; selecting one fills and focuses the composer without sending. Material, container, and responsive rules live in UI globals. Header status uses recognizable ready/building/error/stopped/offline icons with a named, focusable tooltip; connection state takes precedence over run status. Error text uses the destructive foreground token. Settings expose a four-position motion slider, persisted through `@workspace/ui/lib/motion-preference`; OS reduced motion always wins.
- Default floating geometry is 352 × 360 with a 20px lower-right inset. Docked panels fill 100dvh with top 0. The v2 storage key leaves v1 preferences untouched. Desktop supports dragging and edge resizing on both axes. Below 768px, the full page remains beneath a bottom overlay with Compact/Expanded height choices, bounded references, a reachable composer, and visualViewport keyboard handling. Phone presentation never rewrites desktop placement. Collapsed mode is a standalone 56px transparent launcher showing three centered dark-to-yellow layers, with its position persisted in `landing.promptPanel.launcher.v1`. The expanded title is read-only, has no edit/click action, and remains a stable drag handle; rename lives in the settings menu. Each collapse captures the visible panel’s top-left position before the conversation hides, replacing any stale compact position. Desktop panels expand at the current compact position, clamping only to fit their expanded size. An untouched dock restores its side; dragging or keyboard-moving the compact panel away from the dock origin makes it expand there as a floating panel. `use-launcher-drag.ts` supports mouse/touch launcher dragging with a 5px threshold; drag never triggers click-to-open. Pointer up/cancel/lost capture finalize the gesture. Arrow keys on the launcher move 16px (Shift 48px), Enter/Space open. A real drag suppresses click-to-open. Placement clamps to the visual viewport on viewport/element resize; restoration follows the latest compact placement. Projects replaces conversation/composer inside the same panel; returning restores them.

- Keep `PromptPanel` presentational: state belongs in hooks/consumers; panel receives data + callbacks. Theme + navigation passed in from composition site.
- When domain model changes, update `src/domain.ts` + re-export from `src/index.ts`; transport/wire shapes stay in consuming app.
- `src/model-dropdown.tsx`: primary model name in a compact trigger; named popover defaults to Text. Advanced models reveals Text/Image/Vision tabs with roving Left/Right/Home/End focus and linked tab panels. Role descriptions explain responsibilities and Vision locking. Model radio rows retain ArrowUp/Down/Home/End behavior, bottom search, live pricing with readable 12px metadata, static fallback, and provider icons. Selection stays open. Vision-capable text models serve their own vision: live `inputModalities` determines capability when available, static inventory on restore; locked alternatives are disabled and excluded from keyboard navigation. Every Text selection retains `:nitro` routing. `selectLandingModel`, `resolveLandingModels`, and `syncLandingModels` maintain linkage. Keep shared role rules and catalog identifiers aligned with the server.

- Conversations keep result text visible and group thinking/tools under an optional activity summary. Clamp long tool intent headers to two lines; preserve full diagnostics in expanded details. Settings place summarization controls inside Advanced, explain preserved context and earlier summarization at lower thresholds, and retain the 1–100% bounds/default 80.

- `RunElapsed` anchors live elapsed time to server stats and freezes at the final duration; `StepElapsed` renders rolling digits through the shared NumberFlow-based `MotionNumber`. Untimed historical runs do not invent a duration. Opening or closing images does not replay conversation text.
- Image attachments and tool references share `MediaModal`: a thumbnail-to-image transition, contained full-size view, visible loading failure, Escape close, and focus restoration. The global stop shortcut yields Escape to dialogs, menus, and popovers before stopping a run.
- While a live run is generating, the collapsed `ProgressBlob` animates; at rest it is still. Its label remains authoritative, and connection failures take precedence. Keep the blob accessible by name and keyboard, with no visible box behind it and a shadow only beneath its bottom layer.

- Floating desktop panels resize from their top/bottom edges using Up/Down (Shift: 48px), Home, and End or pointer dragging. Height defaults to 360px, has a 240px preferred minimum, fits the viewport, and persists as `height` in panel storage v2. Resizing pins the opposite edge and never implicitly docks. Collapse, reopen, and dock/float transitions retain the chosen floating height. Docked panels remain full-height; phone overlays retain their Compact/Expanded controls.

- Composer tools, model selector, and spend trigger use the same ghost button treatment; only Send, Stop, and active element selection use filled semantic states.
